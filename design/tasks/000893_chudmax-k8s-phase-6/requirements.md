## User stories

1. **As the human**, I want the engine chart to be a pure pointer — a Service without a selector plus an EndpointSlice whose address the installer supplies (empty by default; NOTES say "set this to your engine's address") — giving the cluster a **stable in-cluster name for the external engine** while the real address never enters a public artifact.
2. **As a user installing the web chart**, I get the real harness: Strata with `--engine mock` (in-process scripted MockEngine — the card's "web chart with the mock engine", literally), real `/health`, `/mcp` and `/v1/chat/completions` endpoints, hardened pod settings, and a safe-by-default `STRATA_ALLOWED_HOSTS` knob for in-cluster Service Host names — and the image built here is the same one phase 7's Flagger canary reuses (no throwaway).
3. **As the rehearsal**, I want the mock engine container running **outside kind on the docker bridge** with the engine Service's EndpointSlice pointing at the bridge gateway — so the proof exercises the **exact production topology: pod → selectorless Service → EndpointSlice → external host** (the LAN in production, the bridge in rehearsal) — with no hostNetwork and no in-cluster mock pretending to be external.
4. **As the rehearsal**, I want the umbrella to install engine + web + mcp on kind and prove: `/health` through the engine Service (200), the web pod answering `/health` through its own Service (which also proves the allowedHosts default), and the mcp pod Up with the server answering HTTP 200 (honest no-data) while the fetcher waits for the ExternalArtifact — expected pre-phase-5 — **without duplicating phase 5's commit→tickets proof**.
5. **As CI**, I want `umbrella-kind.yml` to re-prove everything: chart lint/template/kubeconform (both variants), the Strata image built for both architectures from the pinned public source, and the kind install job.
6. **As the human**, I want the standing hygiene: box untouched, no registry push, no LAN address/credential/internal hostname in any public artifact, three labels on every claim, conventional commits, the missing-LICENSE flag, merge authority CoS.
