The ChudMax web — Strata's serve.server with the in-process MockEngine.

    http://{{ include "chudmax-web.fullname" . }}:{{ .Values.port }}

Real endpoints: GET /health, GET /mcp, POST /v1/chat/completions (+ /v1/messages,
/v1/responses). The image is built from the public kingdonb/Strata at the pinned
SHA recorded in the umbrella's README — unpublished until phase 10: build and
load it yourself until then (the umbrella's kind-smoke.sh does, tagged with the
chart's default reference).

The DNS-rebinding guard: without an API key every request passes the Host check
first. This release's allowed Hosts:

    {{ include "chudmax-web.allowedHosts" . }}

(set web.allowedHosts="auto" — the default — for the release's Service DNS names
+ localhost; a list to override; "*" disables the check — discouraged.)

The McpHub wiring (phase 7): set web.mcpConfig to the Claude-Desktop-format
hub config ({"mcpServers": {"tickets": {"url": "http://<mcp-service>:8080/mcp"}}})
and the chart renders it as an inline ConfigMap + the --mcp-config arg — both
pod-template-carried, so Flagger's primary and canary copies inherit it. The
web pods expose Strata's native Prometheus metrics at /metrics?format=prometheus
(set web.podAnnotations with the scrape annotations to let a Prometheus scrape
them).
